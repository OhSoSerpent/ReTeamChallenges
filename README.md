# ReTeamChallenges
A repo with all of the UWEC Blugold CTF teams self designed practice problems\
 \
 \
The plan is to have everyone store the problems they create in here, and other club members can try to solve them. If successful, they can create a writeup in the format shown in the example repo.\
\
Please use the format laid out in the example repo, so we can keep everything organized
